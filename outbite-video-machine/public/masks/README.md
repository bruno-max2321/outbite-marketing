# Masks

Optional PNG/SVG mattes for tighter Chinese-text covers if the default rectangular panels are not enough.

Suggested names:

- `food-header-mask.png` — soft-edged cover for top ~0–31% region
- `subtitle-mask.png` — cover for lower caption band ~68–79% V

The current composition uses solid geometric covers via `FoodComparison` + `SubtitleCover` and does not require these files.
